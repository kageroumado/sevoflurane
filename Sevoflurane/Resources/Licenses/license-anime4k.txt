Anime4K (the anime4k-c shader package)
======================================

Source: https://github.com/bloc97/Anime4K

Anime4K is an optional shader package for the built-in engine's upscaler,
compiled from Anime4K's own shaders. It lives as a replaceable directory
under ~/Library/Application Support/Sevoflurane/Shaders/, carrying this
license and the shaders it was compiled from, and a game is given it in
Settings.
