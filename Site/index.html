Actually native

Real macOS windows, the real menu bar, ⌘-shortcuts, Finder and your default browser — never a translated imitation of them.

Sets itself up

Download, drag to Applications, open. Sevoflurane installs everything it needs and signs you in with Steam's own login. No configuration.

Heals itself

A supervisor watches the machinery and restarts what breaks before you notice. If something needs you, it says so in plain language.

Talks to your agent

A CLI and MCP server ship in the box — ask Claude (or any agent) to install a game, debug a crash, or check a download.

How it works

The Windows Steam client runs headless in a compatibility layer — it keeps doing what it's good at: downloads, cloud saves, ownership, and launching games through Proton-class translation (DXMT on Apple GPUs).

Everything you see is Steam's own interface, rendered by macOS-native WebKit inside real windows, driven over the client's own control channel. Not a re-implementation that breaks when Valve ships an update — the same UI, hosted properly.

Honest limits: games with kernel anti-cheat (EAC, BattlEye) don't run under any Mac translation layer, and Sevoflurane will say so on the game page instead of letting you download 60 GB to find out.

Questions

Is this allowed?
Sevoflurane drives your own Steam client through its own debugging interface, on your own machine. Nothing is redistributed, no DRM is touched — the same ground Steam Deck plugin tools have stood on for years.
What about CrossOver?
If you own CrossOver, Sevoflurane uses it — it's the best engine available and buying it funds Wine development. Without it, a free built-in engine is installed automatically.
How well do games run?
The same as they run under CrossOver/Wine with Apple's and the community's translation stack — many titles are excellent, some aren't. Sevoflurane shows per-game compatibility before you install.
Why the name?
Sevoflurane is the anesthetic known for the smoothest, least irritating induction. The color code on the vaporizer is yellow.
